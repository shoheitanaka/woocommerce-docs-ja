# Getting started

WooCommerce.comマーケットプレイスにようこそ！WooCommerce.comマーケットプレイスは、世界中の信頼できる開発者とマーチャントを結びつけ、パワフルで柔軟なオンラインストアを作成します。

## Wooマーケットプレイスで販売すべき理由

- **WooCommerceマーチャントのグローバルネットワーク**へのアクセス
- 公式WooCommerceマーケットプレイスへの商品掲載による**ブランド認知と信頼**の構築
- **ビジネスの成長をサポートするために設計された収益共有**。
- **WooCommerce マーケティングキャンペーンに掲載される機会**があります。
- アクティブなマーチャントとデベロッパーのコミュニティから**洞察とフィードバック**が得られます。

## ♪ お似合いですか？

私たちは次のような製品を探しています：

[- 実際の加盟店の問題を解決する
- 安全で、文書化され、メンテナンスが行き届いている。
- セキュリティ](https://developer.wordpress.org/apis/security/)、[開発](https://developer.woocommerce.com/docs/extensions/best-practices-extensions/extension-development-best-practices/)、[ユーザーエクスペリエンス](https://developer.woocommerce.com/docs/extensions/ux-guidelines-extensions/best-practices/)のベストプラクティスに従っている。
- 質の高いマーチャントサポートを提供すること
- 直販、サブスクリプション、またはその他の方法を問わず、明確で持続可能なマネタイズモデルを含むこと。

## 協定

WooCommerceマーケットプレイスに参加するには、ベンダーは高品質で安全な製品を提供し、強力なカスタマーサポートを提供し、リスティング、アップデート、価格設定、コミュニケーションに関するWooCommerceのガイドラインに従う必要があります。商取引条件は収益分配モデルに基づいており、売上の70%がベンダーに支払われます。

[マーケットプレイスベンダー規約全文を読む](https://woocommerce.com/woo-vendor-agreement/)。

## 投稿の旅

### ステップ1：製品の準備

1.拡張機能やテーマを構築し、徹底的にテストする。
2.私たちの[技術的](https://developer.woocommerce.com/docs/extensions/best-practices-extensions/extension-development-best-practices/)、[ユーザーエクスペリエンス](https://developer.woocommerce.com/docs/extensions/ux-guidelines-extensions/best-practices/) (UX)、[セキュリティ基準](https://developer.wordpress.org/apis/security/)を満たしていることを確認してください。
3.明確で包括的な[ドキュメント](https://developer.woocommerce.com/docs/extensions/best-practices-extensions/support-and-documentation/)を書く。

### ステップ2：マーケットプレイスに申し込む

詳細な製品情報、デモリンク、テスト方法を提出し、レビューを受けてください。

### ステップ3：製品レビュー

1.私たちのチームは、機能性、セキュリティ、互換性、UXのためにあなたの提出物をレビューします。
2.フィードバックや修正依頼を受け取ることもあります。

### ステップ4：立ち上げと販売

1.承認されると、商品はWooCommerce.comマーケットプレイスに掲載されます。
2.掲載後は、商品のメンテナンスとアップデートを行い、継続的なマーチャントサポートを提供します。
