# Marketplace Content Style Guide

このガイドでは、WooCommerce マーケットプレイスで製品ページとドキュメントを作成するための書式と記述の基準を示します。これらのガイドラインに従うことで、マーケットプレイス全体の一貫性が保たれ、エクステンションを閲覧・購入するマーチャントにとってプロフェッショナルなエクスペリエンスが提供されます。

商品ページの構成、必須要素、アセット仕様については、[商品ページのコンテンツとアセット](/docs/woo-marketplace/product-page-content-and-assets/)を参照してください。

## ライティング・スタンダード

### 製品命名規則

商品コピーでは「WooCommerce商品名」ではなく「WooCommerce商品名」を使用してください。

このフォーマットは、商品名が[商標ルール](https://automattic.com/trademark-policy/)に準拠し、一意の識別子でリードすることを保証し、発見しやすさとわかりやすさを向上させます。

### 文法と句読点

[WooCommerce文法、句読点、大文字表記ガイド](https://woocommerce.com/document/woocommerce-grammar-punctuation-and-capitalization-guide/)を参考にしてください。主なポイントは以下の通りです：

**3つ以上の項目を記載する場合は、オックスフォード・コンマ**を使用してください：

- ✓ "注文の追跡、在庫管理、返金処理"
- ✗ "注文の追跡、在庫管理、返金処理"

**受動態ではなく能動態を使うこと：

- ✓ "注文が発送されると、エクステンションからEメール通知が送信されます。"
- ✗ "注文が発送されると、エクステンションからEメール通知が送信されます。"

**資本金

- 見出しにはセンテンスケースを使用する（最初の単語と固有名詞のみ大文字にする）
- 強調するために全角文字を使用しない
- 商品名、機能、WooCommerce用語を正しく大文字で表記する。

*スペルと用語：***。

- アメリカ英語のスペルを使用する
- ecommerce"（小文字、ハイフンなし）を使用する。
- WooCommerce "を使用してください（"Woocommerce "や "wooCommerce "ではありません）。

## 書式ガイドライン

これらの標準に従って、クリーンで一貫性のある書式を維持してください。カスタムスタイルは、マーケットプレイスのデザインシステムに干渉し、一貫性のないエクスペリエンスを生み出します。

### テキストの書式設定

**しないでください。

- 見出しまたは本文の中央揃え
- デフォルトのテキスト色を変更する
- カスタムのフォントサイズまたはフォントファミリを追加する
- 太字や斜体の書式を過度に使用する

- テキストはすべて左揃え
- 見出しと段落はデフォルトのスタイルを継承させる。
- 太字は重要な用語にのみ控えめに使用する

### 見出し

**しないでください。

- 1ページに1つ以上のH1タグを含める（商品タイトルがH1の役割を果たす）
- 見出しを中央揃えにする
- 見出しにカスタムカラーやカスタムスタイルを適用する

- メインセクションにはH2を使用する
- H2セクション内のサブセクションにはH3を使用する
- 論理的な見出し階層を維持する（レベルを飛ばさない）

### セクションとレイアウト

**しないでください。

- カスタムスタイルのセクションやコンテナを作成
- セクションの周りにボーダーを追加する
- コンテンツエリアに背景色を適用する
- セクション間にカスタムスペーシングを追加する
- カラムにスタイルを追加する

- 標準的な段落ブロックと見出しブロックを使用する
- セクションの間隔はマーケットプレイスのテンプレートに任せる
- スタイルを変更せずにデフォルトの列ブロックを使用する

**しないでください。

- カスタムCSSで箇条書きや数字のデザインをカスタマイズ
- リストアイテム間にカスタムスペーシングを追加
- 2階層以上のネストされたリストの作成

- 標準の順序なしリストまたは順序付きリストブロックを使用する
- 承認されたリスト・クラスをスタイル付きチェックマークに適用する (以下の書式設定ツールを参照)

## 内容の制限

製品ページや文書に絵文字を使用しないでください。絵文字はアクセシビリティの問題を引き起こし、デバイス間で表示が一貫せず、プロらしくない外観になる可能性があります。

- ✗ "🚀 売り上げを伸ばそう！"
- 売上を伸ばそう

### 外部リンク

外部ウェブサイトへのリンクは含めないでください。すべてのサポートとドキュメンテーションのリンクは、マーケットプレイスのURLを指すようにしてください：

- WooCommerce.comでホストされている製品ドキュメントへのリンク
- マーケットプレイスのサポートリソースへのリンク
- 外部のサポートポータル、ドキュメントサイト、ランディングページにリンクしないでください。

## 書式ツール

WooCommerce Marketplaceには、一貫性を保ちながら視覚的に魅力的なコンテンツを作成するためのフォーマットツールがいくつか用意されています。

### スタイル付きリストクラス

これらのCSSクラスを使って、プロフェッショナルなチェックマークリストを作成しましょう：

#### プライマリチェックマークリスト (wccom-tick-list-primary)

太字のチェックマークを緑の丸で囲みます。商品説明の上部にある主なベネフィットリストに使用します。

```html
<ul class="wccom-tick-list-primary">
  <li>Accept payments globally</li>
  <li>Automatic tax calculation</li>
  <li>Real-time shipping rates</li>
</ul>
```

#### 二次チェックマークリスト (wccom-tick-list-secondary)

軽量な緑色のチェックマークを作成します。ページ全体の機能リストや二次コンテンツに使用します。

```html
<ul class="wccom-tick-list-secondary">
  <li>Supports 100+ currencies</li>
  <li>PCI compliant</li>
  <li>Automatic updates</li>
</ul>
```

### 吹き出しボックス

ボックスショートコードを使って、重要な情報を強調しましょう。利用可能なスタイル

#### 情報ボックス

一般的なヒントや役立つ情報については

```plain
[box]This extension requires WooCommerce 8.0 or higher.[/box]
```

このコンポーネントは、`style="info"`の有無にかかわらず使用できる。

#### アラートボックス (style="alert")

警告や重要なお知らせ

```plain
[box style="alert"]Backup your site before updating to the latest version.[/box]
```

#### エラーボックス (style="error")

重大な警告や既知の制限について：

```plain
[box style="error"]This extension is not compatible with multisite installations.[/box]
```

#### 成功ボックス (style="success")

肯定的な確認やベストプラクティスについて：

```plain
[box style="success"]Your API credentials are securely encrypted and stored.[/box]
```

:::info
吹き出しボックスは控えめに使いましょう。使い過ぎるとインパクトが弱くなり、視覚的に乱雑になる。
:::

## ドキュメント基準

製品のドキュメントを作成する際は、以下の追加ガイドラインに従ってください：

### 構造

- 拡張機能が何をするのかを説明する明確なイントロダクションから始めてください。
- "Docs - Installation "というタイトルの同期パターンを使用してください。これは私たちの相互の顧客がWooCommerce.comからの購入をどのようにインストールすべきかを説明しています。
- 製品のすべての機能と設定を文書化してください。
- 一般的な問題に対するトラブルシューティングガイダンスを提供する

詳細なドキュメンテーションの枠組みについては、[サポートとドキュメンテーションのベストプラクティス](https://woocommerce.com/document/extension-development-best-practices/#support-and-documentation)を参照してください。

### 画像とスクリーンショット

ビジュアル・コンテンツを追加する場合：

- 最新のWordPress管理画面のカラースキームを使用する
- 異なるテーマのドキュメントを作成する場合を除き、最近のWordPressのコアテーマを使用すること
- スクリーンショットは鮮明で見やすいものにすること
- ファイルサイズを最適化する
- スクリーンショットに機密情報や個人情報を含めない
- アクセシビリティのため、すべての画像にaltテキストを追加する
